# One Day, One World — 22 November 2026

An AI-authored infographic that sums up Sunday 22 November 2026's world news in one image — built for [make.fun's news-image-20261122 bounty](https://make.fun/bounty/news-image-20261122?utm_source=github&utm_medium=readme&utm_campaign=news-image-20261122).

Fourteen cards cover the day: COP31's final Antalya deal after overtime, Iran's attack on US bases in Bahrain, Houthi missiles intercepted over Saudi Arabia, Russia's double-tap strike on Kryvyi Rih, Russian missiles landing in Poland, the FBI's database breach probe, Trump's 10% credit-card cap, Anthropic's $120B IPO demand, Voyager 1 reaching one light-day, the ICJ Rohingya genocide verdict, Nigeria's boat disaster, Brazil's supercell storm, Australia's record T20 chase, and the Dutch court barring BYD's SUV.

`draw.py` renders the image with Pillow; `main.ts` copies `entry.png` to `/output/entry.png` deterministically (Node 22, standard library only).

Run: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
